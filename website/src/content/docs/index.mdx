## Watch it melt

<Demo route="product">

A watch, a laptop, a phone, a Mac mini: product shots cut out to their outline, tall and wide in turn. Swipe or tap the phone and watch one outline pour into the next, while the title and the button slide underneath.

- The blob takes the shape of the product it leaves and reforms as the next one, drawn with Skia on the UI thread.
- At rest the image is sharp: the effect fades out completely between swipes.
- The button takes the color of the product in view through `renderFooter`.

[How it is built, with the full source →](/expo-morph-carousel/examples/product/)

</Demo>

## In 30 seconds

```bash
npx expo install expo-morph-carousel @shopify/react-native-skia expo-file-system \
  react-native-reanimated react-native-worklets react-native-gesture-handler
```

<Demo route="basic">

```tsx
<MorphCarousel
  data={shapes}
  getImage={(s) => s.image}
  style={{ height: 520 }}
  renderItem={({ item }) => <Text>{item.title}</Text>}
  renderFooter={({ next }) => <Button title="Continue" onPress={next} />}
/>
```

That is all the phone on the left needs. [Usage](/expo-morph-carousel/usage/) has the whole file, ready to copy.

</Demo>

## What it does

<CardGrid>
  <Card title="Liquid morph" icon="star">
    Between two pages the image dissolves into a blob and reforms as the next one, drawn with Skia on the UI thread. At rest the image is never blurred.
  </Card>
  <Card title="Page layouts" icon="random">
    Slide, parallax, stack, coverflow, a solid 3D cube, flip, tinder, or your own worklet. Pages narrower than the carousel show their neighbors.
  </Card>
  <Card title="Slots" icon="puzzle">
    Replace the pagination, each dot, or draw over and behind the media. Every slot gets the position as a shared value, so it moves with the finger.
  </Card>
  <Card title="Remote images" icon="cloud-download">
    A disk cache with expiry, srcset-style picking by size, priorities and prefetching, so swipes rarely wait.
  </Card>
  <Card title="Pager behavior" icon="seti:pipeline">
    Snap, momentum or free, loop, autoplay, vertical, right-to-left, tap to navigate, and a ref API to drive it.
  </Card>
  <Card title="iOS, Android, web" icon="laptop">
    The same code on every platform, with screen reader and keyboard support.
  </Card>
</CardGrid>

## Make it yours

Start from an example, then go further with the [slots](/expo-morph-carousel/guides/slots/): your own pagination, dots, overlays and backgrounds, all driven by the carousel's position on the UI thread. Or write a [page layout](/expo-morph-carousel/guides/page-layouts/) or a [media effect](/expo-morph-carousel/guides/media-effects/) as a worklet.

Also from the same author: [expo-morph-menu](https://github.com/anhtuank7c/expo-morph-menu), a menu that morphs out of its button.
