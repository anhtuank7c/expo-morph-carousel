### How it works

1. `getImage(item, index, target)` builds an imgix URL for the size the carousel measured.
2. The disk cache keeps the photos for as long as their `Cache-Control` says (`respectHttpHeaders`); the panel shows its live stats.
3. The home screen prefetches these photos at the same size, so this screen opens with them ready.
4. Toggles switch tap to navigate and `liquid.preserveShape` (keep the corners while morphing).
