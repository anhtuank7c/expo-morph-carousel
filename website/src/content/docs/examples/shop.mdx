### How it works

1. The gallery is a square media area (`mediaHeight={width}`, `mediaFit="cover"`, `mediaPadding={0}`); the colors are its pages.
2. The `Pagination` slot is a strip of thumbnails. Each frame reads the carousel's `position` on the UI thread, so it follows the finger, and a tap calls `scrollTo(i)`.
3. The color swatches below call `ref.scrollTo(i)`; `onIndexChange` keeps the title, the stock line and the cart button color in sync.
4. Tap the photo itself to go to the next color (`tapToNavigate={{ area: 'media' }}`), which leaves the buttons on the page alone.
