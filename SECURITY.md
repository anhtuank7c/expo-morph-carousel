# Security policy

## Supported versions

Security fixes are released for the latest minor version on npm.

## Reporting a vulnerability

Do not open a public issue. Report it privately through GitHub: on the repository page, open **Security → Report a vulnerability** ([direct link](https://github.com/anhtuank7c/expo-morph-carousel/security/advisories/new)).

Include the affected version, a description of the problem and, if possible, steps to reproduce it. You will get a reply within 7 days. Once a fix is published, the advisory is made public with credit to the reporter unless you ask otherwise.

The package has no native code of its own. It loads only the images you pass to it, and on web the CanvasKit file from the location you configure.
